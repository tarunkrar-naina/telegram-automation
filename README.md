# 🤖 Telegram AI Agent

### Groq AI + SerpAPI + Supabase + Render

An intelligent Telegram AI Agent that answers questions, searches the web for real-time information, and automatically publishes content to a Telegram channel.

The agent combines AI-powered responses, live web search, database storage, and scheduled content publishing in one automated system.

## ✨ Features

* 🤖 **AI-Powered Responses** — Get intelligent answers using Groq AI.
* 🔎 **Live Web Search** — Search for the latest news, technology updates, and other information using SerpAPI.
* 💬 **Telegram Integration** — Interact with the AI agent directly through Telegram.
* 📢 **Automatic Channel Posting** — Send generated content to a Telegram channel.
* 📰 **Trending News** — Automatically discover and publish trending news.
* 🧠 **Chat History** — Store conversation history using Supabase.
* 🔄 **Duplicate Content Detection** — Check previously published content to reduce duplicates.
* 🎯 **Automated Quizzes** — Publish engaging quiz content.
* 💡 **Motivational Content** — Generate motivational posts with images.
* ⏰ **Scheduled Publishing** — Automatically publish content three times a day.
* 🔐 **Owner Authentication** — Restrict bot commands to the authorized owner.
* ☁️ **Cloud Deployment** — Deploy the application using Render.

## 🛠️ Technologies Used

* Python
* Flask
* Groq AI API
* SerpAPI
* Telegram Bot API
* Supabase
* Unsplash API
* Gunicorn
* Render

### 2. Automatic Content Publishing

The background scheduler runs at **9:00 AM, 2:00 PM, and 8:00 PM**, according to the configured timezone.

## 🎯 Project Goals

The goal of this project is to build a personal AI assistant that combines conversational AI, web search, Telegram automation, and scheduled content publishing in a single application.
